# 微信公众号 IP 白名单设置指南

## 问题说明

当在手机上使用小程序发布文章到微信公众号时，可能会遇到以下错误：

```
错误代码: 40164
错误信息: invalid ip xxx.xxx.xxx.xxx, not in whitelist
```

这是因为微信公众号 API 要求调用 `access_token` 接口时，服务器 IP 必须在白名单中。

---

## 重要提示：开发者工具 vs 真机预览

### 问题现象
- **开发者工具**：发布成功 ✅
- **真机预览/手机操作**：发布失败，提示 IP 被拒绝 ❌

### 原因分析
小程序在开发者工具和真机上运行时，网络请求的出口 IP 可能不同：

| 环境 | 请求路径 | 出口 IP |
|------|----------|---------|
| 开发者工具 | 本地 → 服务器 | 服务器 IP (39.108.254.228) |
| 真机预览 | 微信服务器 → 服务器 | 微信服务器 IP（多个） |

**解决方案**：需要将微信服务器 IP 也添加到白名单中。

---

## 解决方案

### 第一步：获取微信服务器 IP 地址

当真机操作报错时，错误信息会显示具体的 IP 地址。例如：

```
invalid ip 101.226.xxx.xxx, not in whitelist
```

**请记录这个 IP 地址**，这就是需要添加到白名单的 IP。

### 第二步：登录微信公众号后台

1. 打开浏览器，访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 使用公众号管理员账号登录

### 第三步：进入 IP 白名单设置

1. 在左侧菜单中找到 **设置与开发**
2. 点击 **基本配置**
3. 在右侧找到 **IP白名单** 区域
4. 点击 **修改** 按钮

### 第四步：添加所有必要的 IP 地址

需要添加的 IP 地址列表：

```
# 主服务器 IP
39.108.254.228

# 微信服务器 IP（根据错误提示添加）
# 常见的微信服务器 IP 段：
101.226.0.0/16
140.207.0.0/16
183.3.0.0/16
```

**注意事项：**
- 如果报错提示的 IP 不在上述列表中，请将报错的 IP 也添加进去
- 每个公众号最多可以设置 20 个 IP 地址
- 支持 IP 段设置，如 `101.226.*.*`

### 第五步：管理员扫码确认

添加 IP 后，需要公众号管理员使用微信扫码确认才能生效。

### 第六步：验证设置

设置完成后，在手机上重新尝试发布文章。

## 常见问题

### Q1: 为什么开发者工具成功，手机上失败？

微信小程序在开发者工具中运行时，请求直接从本地发出，出口 IP 是服务器 IP（39.108.254.228）。

但在真机上运行时，请求会经过微信的服务器中转，出口 IP 是微信服务器的 IP。微信公众号会校验请求来源 IP，所以需要将微信服务器 IP 也加入白名单。

### Q2: 我是多账号用户，每个公众号都需要设置吗？

**是的**，每个公众号都需要单独设置 IP 白名单。如果您管理多个公众号，需要分别登录每个公众号后台进行设置。

### Q3: 设置后多久生效？

设置后立即生效，无需等待。

### Q4: 我不知道服务器的 IP 地址怎么办？

当前小程序使用的服务器 IP 是：`39.108.254.228`

真机请求的出口 IP 会在错误信息中显示，请根据错误提示添加。

### Q5: 错误提示中的 IP 和已知 IP 都不一样？

请将错误提示中显示的 IP 也添加到白名单中。微信可能有多个服务器 IP，不同地区、不同时间可能使用不同的出口 IP。

### Q6: 设置了 IP 白名单还是报错？

1. **检查 IP 是否正确**：确认没有多余的空格或换行
2. **检查管理员是否扫码确认**：设置 IP 后必须管理员扫码确认
3. **等待几分钟**：极少数情况下可能需要几分钟生效
4. **检查 AppID 和 AppSecret**：确认配置的凭证正确
5. **添加更多 IP**：如果还有新的 IP 报错，继续添加

### Q7: 有没有办法一次性解决？

微信公众号要求 IP 白名单是安全策略，无法绕过。建议：

1. 将 `39.108.254.228` 和常见的微信 IP 段都添加进去
2. 如果还有新的 IP 报错，及时添加

## 技术说明

### API 调用流程

```
开发者工具：
小程序(本地) → 服务器(39.108.254.228) → 微信公众号 API
                        ↓
                 IP 验证：39.108.254.228 ✅

真机预览：
小程序(微信服务器) → 服务器(39.108.254.228) → 微信公众号 API
                              ↓
                       IP 验证：微信服务器 IP ❌ (如果不在白名单中)
```

### 相关错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 40164 | IP 不在白名单中 | 添加报错的 IP 到白名单 |
| 40001 | AppSecret 错误 | 检查 AppSecret 配置 |
| 40013 | AppID 无效 | 检查 AppID 配置 |
