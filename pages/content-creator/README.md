# 多平台排版优化技能 - 使用说明

## 功能概述

本小程序页面集成了完整的多平台排版优化技能，包括：

### 1. 多平台排版优化
- **微信公众号**：HTML排版、智能高亮、秀米模板兼容
- **小红书**：Emoji增强、结构化标记、标签优化
- **知乎**：Markdown格式、引用块、专业严谨风格
- **抖音**：口语化、短句节奏、3秒钩子设计
- **B站**：活泼互动、系列化内容、弹幕引导

### 2. 内容优化工具
- 爆款标题生成（4种风格模板）
- 标题评分系统（0-100分）
- 内容结构分析
- SEO优化建议
- 内容质量检查

### 3. 图片工具
- **图片搜索**：基于关键词搜索高质量配图
- **AI生成**：根据提示词生成专属配图
- **智能建议**：自动分析内容推荐配图关键词
- **封面生成**：一键生成平台适配的封面图
- **批量配图**：自动为长文生成多张配图

## 使用方法

### 基础使用
1. 选择热点话题
2. 配置创作参数（风格、长度、平台）
3. 点击生成内容
4. 使用排版优化工具进行优化

### 排版优化工具栏

生成内容后，在结果页面顶部会出现排版优化工具栏：

- **⚙️ 排版选项**：配置HTML排版、智能高亮、Emoji等
- **✨ 标题优化**：生成多个优化后的标题供选择
- **🖼️ 配图工具**：搜索或AI生成图片
- **📊 质量分析**：分析内容质量并给出建议
- **🌐 多平台预览**：预览内容在各平台的展示效果

### 图片工具使用

#### 搜索图片
1. 点击"配图工具"打开图片面板
2. 选择"搜索图片"模式
3. 输入关键词或使用智能建议
4. 点击"搜索"获取图片
5. 选择需要的图片，点击"插入到内容"

#### AI生成图片
1. 选择"AI生成"模式
2. 输入图片描述（如：现代科技城市，蓝色调）
3. 选择生成类型：
   - **生成配图**：生成单张配图
   - **生成封面**：生成平台适配的封面
   - **批量配图**：自动为文章生成多张配图
4. 生成的图片可以直接插入内容

### 标题优化

1. 点击"标题优化"
2. 系统会生成4种风格的标题：
   - 数字型（如：5个技巧...）
   - 疑问型（如：为什么...）
   - 对比型（如：从...到...）
   - 热点型（如：...来了，怎么办）
3. 每个标题都有评分，选择评分最高的

### 多平台发布

1. 点击"多平台预览"
2. 查看内容在各平台的展示效果
3. 检查字数限制和格式适配
4. 点击"导出全部"复制所有平台内容

## 配置说明

### 图片搜索API配置（可选）

如需使用更高质量的图片搜索，可在 `image-service.js` 中配置：

```javascript
this.searchConfig = {
  unsplash: {
    apiKey: 'YOUR_UNSPLASH_API_KEY'
  },
  pexels: {
    apiKey: 'YOUR_PEXELS_API_KEY'
  }
};
```

### AI生成配置（可选）

如需使用AI生成图片，需要配置相应的服务提供商：

```javascript
this.aiConfig = {
  providers: {
    coze: {
      enabled: true,
      // Coze配置
    },
    openai: {
      enabled: true,
      // OpenAI配置
    }
  }
};
```

## 注意事项

1. **默认使用免费图片源**：未配置API Key时，使用免费的 Picsum 服务
2. **图片占位符**：AI生成未配置时，显示占位图提示
3. **平台适配**：各平台有特定的尺寸和格式要求，系统会自动适配
4. **字数限制**：系统会检查并提示各平台的字数限制
