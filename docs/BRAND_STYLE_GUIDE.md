# 品牌风格规范指南

## 🎨 核心设计体系

### 配色规范
- **主色**：紫粉渐变 `#9333EA → #EC4899`
  - 用于：顶部栏、选中态标签、核心按钮
- **背景色**：极浅灰 `#F8F9FA`
  - 用于：页面主体背景，营造清爽专业氛围
- **辅助色**：
  - 橙色 `#F97316`：热度标识、序号
  - 浅粉/浅紫：标签背景
  - 深灰 `#333333`：标题文字
  - 中灰 `#666666`：正文文字
  - 浅灰 `#999999`：辅助说明文字

### 排版规范
- **标题**：加粗，清晰醒目
- **正文**：常规字重，灰色辅助说明
- **按钮/标签文字**：强制垂直水平居中，内边距上下左右至少12px
- **字体大小**（rpx单位）：
  - 超大标题：40rpx
  - 大标题：36rpx
  - 标题：32rpx
  - 正文：28rpx
  - 小字：24rpx
  - 极小字：20rpx

### 插画规范
- **风格**：扁平化矢量插画，线条简洁、色块明快
- **特点**：无渐变/阴影，仅作为功能点缀
- **图标库**：场记板、铅笔、摄像机、钱袋、灯泡、数据图表等均为同质感插画

### 布局规范
- **卡片/模块**：大圆角（16-20px），白色背景，轻微阴影提升层级
- **页面留白**：间距统一（模块间距20px，卡片内边距16px）
- **列表布局**：
  - 单列信息流：默认布局
  - 网格布局：一行2列，卡片间距16px

## 🔧 开发实现规范

### 样式变量定义
```css
/* 颜色变量 */
--color-primary-start: #9333EA;
--color-primary-end: #EC4899;
--color-background: #F8F9FA;
--color-orange: #F97316;
--color-text-dark: #333333;
--color-text-medium: #666666;
--color-text-light: #999999;

/* 圆角变量 */
--border-radius-large: 32rpx;
--border-radius-medium: 24rpx;
--border-radius-small: 16rpx;

/* 阴影变量 */
--shadow-light: 0 2rpx 8rpx rgba(0, 0, 0, 0.06);
--shadow-medium: 0 4rpx 12rpx rgba(0, 0, 0, 0.1);
--shadow-primary: 0 4rpx 12rpx rgba(147, 51, 234, 0.3);
```

### 强制约束
1. **所有按钮文字**：必须使用 `display: flex; justify-content: center; align-items: center;` 实现绝对居中
2. **内边距**：按钮/标签内边距上下左右至少12px
3. **颜色一致性**：禁止新增额外颜色，必须复用现有配色体系
4. **图标风格**：所有图标必须保持扁平化矢量插画风格
5. **页面底部**：无多余空白，信息层级清晰不杂乱

## 📱 分页面适配规范

### 1. 首页（AI短视频创作）
- **顶部栏**：紫粉渐变，标题居中，文字白色
- **输入区**：大圆角白色卡片，搜索框细微描边
- **功能导航**：4个大圆角图标卡片，扁平化插画图标
- **标签栏**：胶囊状，"全部"标签为紫粉渐变，其他为浅灰底
- **内容流**：白色大圆角卡片，左侧圆形紫色序号

### 2. 自媒体创作/热点创作页面
- **顶部栏**：紫粉渐变，标题居中
- **热点卡片**：白色大圆角，左侧圆形序号（橙色/灰色）
- **进度条**：热度/适合度用横向进度条（橙色/紫色）
- **核心按钮**："立即创作/开始创作"为紫粉渐变，文字白色，宽度适中

### 3. 模板中心页面
- **布局**：一行2列网格，卡片间距16px
- **卡片结构**：左侧扁平化插画图标，右侧标题+描述+浅粉标签
- **使用按钮**：紫粉渐变，文字白色，严格居中

### 4. 智能体页面
- **状态栏**：紫粉渐变背景，智能体状态标识清晰
- **对话区域**：白色卡片，用户消息紫粉渐变，AI消息白色
- **输入区**：固定底部，紫粉渐变发送按钮
