# 小程序 request 合法域名配置指南

## 问题现象

- **开发者工具**：API 调用正常 ✅
- **真机预览/手机操作**：API 调用失败 ❌

**错误信息**：
```
request:fail url not in domain list
```

或

```
IP 被拒绝 / 连接超时
```

---

## 原因分析

微信小程序在真机上运行时，会严格校验网络请求的域名必须在 `request合法域名` 列表中。开发者工具默认不校验，所以开发时正常，但真机上会失败。

---

## 解决方案

### 第一步：登录小程序后台

1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 使用小程序管理员账号登录

### 第二步：进入域名配置

1. 左侧菜单：**开发** → **开发管理**
2. 点击 **开发设置** 标签
3. 找到 **服务器域名** 区域
4. 点击 **修改** 按钮

### 第三步：添加 request 合法域名

在 **request合法域名** 中添加以下域名：

```
# 服务器 API
https://39.108.254.228

# 智谱 AI API
https://open.bigmodel.cn

# 微信公众号 API（如果需要）
https://api.weixin.qq.com

# 图片资源域名（如果需要）
https://mmbiz.qpic.cn
https://gcore.jsdelivr.net
```

**注意事项**：
1. 域名必须是 HTTPS 协议
2. 域名必须经过 ICP 备案
3. 每月只能修改 5 次

### 第四步：管理员扫码确认

添加域名后，需要管理员扫码确认才能生效。

### 第五步：重新编译测试

1. 回到微信开发者工具
2. 点击 **清缓存** → **全部清除**
3. 重新编译项目
4. 在真机上测试

## 如果域名是 IP 地址

如果使用 IP 地址（如 `39.108.254.228`），有以下限制：

1. **必须使用 HTTPS**：不支持 HTTP
2. **需要配置证书**：服务器需要有有效的 SSL 证书
3. **可能被拒绝**：小程序对 IP 地址的域名审核较严格

**推荐方案**：
- 使用域名而不是 IP 地址
- 或者将 API 部署到云函数中，通过云函数调用外部 API

---

## 云函数方案（推荐）

如果无法配置域名白名单，可以使用云函数作为中转：

```
小程序 → 云函数 → 外部 API
```

云函数不受 `request合法域名` 限制，可以访问任何外部 API。

### 已配置的云函数

项目中已配置以下云函数用于 API 调用：

| 云函数 | 用途 | 外部 API |
|--------|------|----------|
| `glm-api` | 智谱 AI API 调用 | open.bigmodel.cn |
| `social-media-proxy` | 社交媒体发布 | api.weixin.qq.com |
| `wechat-publish-api` | 微信公众号发布 | api.weixin.qq.com |

### 使用云函数调用

```javascript
// 不推荐：直接调用外部 API
wx.request({
  url: 'https://open.bigmodel.cn/api/...',
  // 真机会失败
});

// 推荐：通过云函数调用
wx.cloud.callFunction({
  name: 'glm-api',
  data: { action: 'chat', data: {...} },
  success: res => { ... }
});
```

## 常见问题

### Q1: 域名已添加但还是失败？

1. **检查协议**：必须是 HTTPS，不支持 HTTP
2. **检查证书**：服务器证书必须有效
3. **清除缓存**：开发者工具中清除缓存后重试
4. **等待生效**：极少数情况需要几分钟生效

### Q2: IP 地址无法添加？

IP 地址添加到 request 合法域名有限制：
- 必须是 HTTPS
- 需要有有效的 SSL 证书
- 审核可能被拒绝

**解决方案**：使用域名或云函数中转

### Q3: 每月只能修改 5 次怎么办？

合理规划域名配置，一次性添加所有需要的域名。

### Q4: 不想配置域名怎么办？

使用云函数作为 API 中转：
- 云函数不受域名白名单限制
- 可以访问任何外部 API
- 更安全（API Key 不暴露在前端）
